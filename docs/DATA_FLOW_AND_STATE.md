# זרימת נתונים ומקור האמת (Data Flow & Source of Truth)

## עקרון מרכזי: השרת הוא מקור האמת

- **מסד הנתונים והשרת** מגדירים את המצב הנכון של הנתונים.
- **הלקוח (Frontend)** הוא תצוגה של המצב; כל עדכון עובר דרך ה-API ומתעדכן במסך לפי **תשובת השרת**.

## עדכון רשומה בודדת (utation)

### הדרך הנכונה

1. **שליחה לשרת**: `PUT /orders/:id` (או `PATCH`) עם הנתונים המעודכנים.
2. **עדכון state לפי תשובה**: השרת מחזיר את המסמך המעודכן (`res.json(order)`). הלקוח מעדכן **רק את הרשומה הזו** ב-state (רשימת הזמנות, עמוד נוכחי וכו') לפי התשובה.
3. **ללא refetch של כל הרשימה**: אין צורך ב-`GET /orders/paginated` אחרי עדכון של הזמנה אחת. זה חוסך עומס, מקצר זמני תגובה ומונע race conditions.

### עדכון אופטימי (Optimistic Update) – אופציונלי

- **למה**: חוויית משתמש מהירה – המשתמש רואה שינוי מיד.
- **איך**: מעדכנים את ה-UI מיד עם הנתונים החדשים; שולחים לשרת; כשהתשובה חוזרת – **מחליפים את הרשומה בתשובת השרת** (מקור האמת). אם השרת מחזיר שגיאה – מחזירים את הרשומה למצב הקודם ומציגים הודעת שגיאה.
- **חשוב**: גם בעדכון אופטימי, **אחרי הצלחה** משתמשים בתשובת השרת (לא נשארים עם הנתונים האופטימיים בלבד), כדי שנורמליזציה או לוגיקה בצד שרת יישמרו ב-state.

## מה לא לעשות

- **Refetch של כל הרשימה אחרי mutation בודד**: יוצר עומס מיותר, איטיות, וסיכון לחוסר עקביות (למשל אם רשימה מתעדכנת בזמן שהבקשה בדרך).
- **להשאיר רק עדכון אופטימי בלי להחליף בתשובת השרת**: ה-state עלול לא reflected שינויים שהשרת עושה (תאריכים, IDs וכו').

## סיכומים (Totals / Summary)

- אחרי עדכון רשומה בודדת, סיכומים (סה"כ, יתרה וכו') יכולים להיות מעט לא מעודכנים עד לטעינה/סינון הבא.
- חלופות: חישוב סיכום מהעמוד הנוכחי ב-client (קירוב), או endpoint נפרד קל לסיכומים בלבד (`GET /orders/summary?filters=...`) שמעדכן רק את הסיכום.

## סיכום

| פעולה              | פעולה נכונה                                      |
|--------------------|---------------------------------------------------|
| שינוי סטטוס הזמנה  | עדכון אופטימי → PUT → עדכון state מתשובת השרת   |
| שמירת הזמנה        | PUT/POST → עדכון state מתשובת השרת (ללא refetch) |
| טעינת רשימה       | GET paginated רק כשמשנים סינון / עמוד / דף      |
